# Laya Vision demo

Ask calibrated yes/no (`noul`) and multiple-choice (`choice`) questions about an image. The Space runs [thaitea/laya-vision-smolvlm-256m](https://huggingface.co/thaitea/laya-vision-smolvlm-256m) on CPU, and the code is at [r33drichards/laya-vision](https://github.com/r33drichards/laya-vision).

The example photo is "Cat November 2010-1a" by Alvesgaspar, CC BY-SA 3.0, from Wikimedia Commons.
